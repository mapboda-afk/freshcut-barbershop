FreshCut Barbershop 💈

A modern, responsive barbershop website built with HTML, CSS, and JavaScript by Map_Technologies.

Features

* Responsive mobile, tablet, and desktop layouts
* Mobile navigation menu
* Services and pricing cards
* Service-specific WhatsApp booking links
* Smooth scrolling and active navigation
* Accessible navigation and keyboard support
* SEO-friendly metadata
* Automatic copyright year

Technologies

* HTML5
* CSS3
* Vanilla JavaScript

Getting Started

1. Clone or download this repository.
2. Open index.html in your browser.
3. Replace the example WhatsApp number in the CONFIG section with the real business number before publishing.

Project Purpose

This project demonstrates responsive web design, accessible navigation, and a simple appointment-request experience for small businesses.
